# プロジェクトナレッジ

Claude のプロジェクト機能で品質を管理するためのファイル群。ホームのチャットには
スクリプトによる関門がないため、ここに置いたルールが唯一の歯止めになる。

## 置き方

1. `00_プロジェクト指示.md` の `----` で囲まれた部分を、**プロジェクトのカスタム指示欄**に貼る
2. 残りの 3 ファイルを**プロジェクトナレッジに添付**する
   - `レポート作成ルール.md`
   - `Notion運用ガイド.md`
   - `科目別メモ.md`
3. Notion コネクタを有効にする（課題DB・文献DB を読み書きするため）

**添付だけでは遵守は保証されない。** カスタム指示欄に 1 を貼って初めて、
ファイルが強制力を持つ。

## 正本はここ

`レポート作成ルール.md` がルールの正本である。同じ内容が Notion の「設定 > 指示文」
にも置いてあるが、あちらはプロジェクトを使わないチャット向けの写しにすぎない。
**片方を直したら必ず両方直すこと。**

Claude Code で作業するときは `prompts/report_generate.md` が同じルールを指している。

## 更新するとき

科目が増えたら `科目別メモ.md` に追記する。ルール自体を変えたら
`レポート作成ルール.md` を直し、Notion の「設定 > 指示文」と `SPEC.md` も揃える。
