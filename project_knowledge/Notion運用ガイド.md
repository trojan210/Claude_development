# Notion 運用ガイド

レポートと文献をどこに、どの形で記録するか。Notion のトップページは「一橋大学」。

---

## 全体構成

```
一橋大学
├─ ダッシュボード（締切一覧・進行状況・未検証文献）
├─ 課題DB          レポート課題の管理。ページ本文＝確定版レポート本文
├─ 文献DB          参考文献の蓄積。卒論の資産になる中核
├─ 卒業論文        章立てページツリー
└─ 設定            運用ルール・執筆ルール・指示文・DB定義・技術メモ
```

---

## 課題を始めるとき

課題DB に行を作り、次を埋める。

| プロパティ | 入れるもの |
| --- | --- |
| 課題名 | 課題の名前 |
| 科目 | 選択肢にない科目は追加する |
| 担当教員 | |
| 年度学期 | `2026-秋` の形式 |
| 締切 | 時刻まで入れる |
| 指定字数 | 下限だけの課題でもその数値を入れる。「目標字数」が 1.25 倍で自動計算される |
| 引用形式 | 指定がなければ「指定なし」。既定で APA が適用される |
| 課題要件 | 設問文をそのまま貼る |
| ステータス | 未着手 |

## 書き終えたとき

- 本文は課題ページの**本文**に入れる。プロパティではない
- **実字数**にコードで数えた字数を入れる。「充足率」が 1.25 前後なら狙いどおり
- **使用モデル・生成日時・指示概要**を必ず埋める。AI 利用申告に使う
- ステータスを 生成済 → 推敲中 → 確定 → 提出済 と進める
- 提出したら**提出日**を入れる

## 文献を登録するとき

文献DB は**引用形式に依存しない生データのみ**を保持する。APA 文字列などは整形して
作るものなので、「APA形式の文字列」といったプロパティは作らない。同じ文献を形式違いで
重複登録することになるためである。

### 出典検証済のルール

<!-- ここがこの仕組みの要である -->

**「出典検証済」にチェックを入れてよいのは、DOI 照会が成功したか、PDF 実物を確認した
文献だけである。** 手入力しただけの文献は未検証のまま残す。

本文に引用してよいのは検証済の文献だけなので、未検証のまま放置すると使えない。
ダッシュボードの「⚠️ 未検証の文献」ビューが常に空になるよう維持する。

### 入力のきまり

- **著者** は `姓, 名; 姓, 名` の形式で統一する。表記が揺れると並べ替えも引用整形も壊れる
- **筆頭著者姓** を別に入れる。並べ替えと著者-年式引用に使う
- **種別**は実態に合わせて選ぶ。会計基準・法令・企業開示資料・統計データベースも種別として用意してある
- **適用時点**は会計基準で必須。基準は改正される
- **参照日**は Web 資料・開示資料・統計で必須

## 卒業論文

章は DB ではなくページツリーで管理する。文献DB の**使用先章**プロパティで章と文献を
紐付ける。**章を追加したら、この多選択肢にも章名を追加すること。** 忘れると章別の
参考文献リストが生成できない。

章の作業段階は 構想 → 執筆 → 指導反映待ち → 固め。

実証研究を想定し、骨組みに「10 データ」「11 分析ノート」を含めてある。データ加工・
推定コードはリポジトリの `analysis/` に置く。

---

## 草稿の版管理

草稿は Git で管理し、**Notion には確定版のみ**を置く。課題DB の「確定コミット」に
コミットハッシュを入れておけば、Notion から Git 履歴を辿れる。

ホームのチャットだけで作業した場合は Git 履歴が残らない。重要な課題は Claude Code 側で
確定させる。
