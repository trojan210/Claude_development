# claude_development

スマホ用 Web アプリの開発リポジトリ。

## NEON BREACH — 横画面スマホ FPS

`index.html` 単体で動く、横画面前提のファーストパーソン・シューター。
ビルド不要・外部ライブラリなし・画像や音声の素材ファイルなしで、ブラウザで開けばそのまま遊べる。

```
open index.html          # ローカルで直接開く
npx serve .              # またはローカルサーバ経由
```

### 中身

| 要素 | 実装 |
| --- | --- |
| 描画 | 自前のレイキャスティングエンジン（DDA・床/天井キャスト・Zバッファ付きビルボード） |
| ライティング | ランプから塗り広げる床面ライトマップ（壁で遮られるので通路は暗くなる） |
| テクスチャ | 全てコード生成（fBm ノイズ + パネル生成） |
| スプライト | Canvas 2D で手続き的に描画して 2 倍解像度でベイク |
| 音 | WebAudio で合成（銃声・被弾・扉・警報など、音声ファイルなし） |
| ステージ | シード固定の BSP 生成。同じステージは毎回同じ地形 |
| 敵 | SEC-DROID（連射ヒットスキャン）/ HUNTER（浮遊・プラズマ）/ BRUTE（重装・榴弾＋近接） |
| 武器 | SIDEARM（単発）/ BREACHER（散弾 9 発）/ VECTOR（フルオート） |
| 保存 | 設定とステージ記録を localStorage に保存 |

### 操作

- **スマホ**: 左半分ドラッグ＝移動スティック（前方に倒し切るとダッシュ）、右半分ドラッグ＝視点、
  FIRE / RELOAD / WPN / RUN ボタン。扉は近づくと自動で開く。
- **PC**: WASD 移動、マウス視点（画面クリックでロック）、左クリック射撃、R リロード、
  1 / 2 / 3 武器切替、Q 切替、Shift ダッシュ、Esc ポーズ。

### 目標

キーカードを回収して脱出ポッドへ到達するとステージクリア。クリアで次ステージが解放される。
