# BALI BLUE — バリ島ダイビング・シミュレーター

スマホ／PC のブラウザで動く、リアル志向のスキューバダイビング・シミュレーター（Three.js / WebGL）。
画像・音声ファイルは一切使わず、海・生物・音はすべてプロシージャル生成。

- 開発ログとコードの保管先は Notion。運用は [NOTION.md](./NOTION.md) を参照。

## ダイブサイト

| サイト | 内容 |
| --- | --- |
| トランベン — USAT リバティ号 | 黒い火山砂の斜面に横たわる全長120mの沈船。ソフトコーラル・ウミウチワ、ギンガメアジのトルネード、タイマイ、カンムリブダイ |
| ヌサ・ペニダ — マンタポイント | 石灰岩の巨岩が転がる台地。ナンヨウマンタがクリーニングステーションを旋回 |

## 海のリアルさのための実装

| 要素 | 手法 |
| --- | --- |
| 水の色 | 波長別（R/G/B）の吸収係数・散乱係数による消散。深くなるほど・遠いほど赤が消える |
| 水中の霞み | 視線方向の一次散乱を解析的に積分（深さで変わる日射＋前方散乱の位相関数） |
| 光の筋（ゴッドレイ） | 視線レイマーチで、水面波が作る集光パターンを体積的に積算 |
| コースティクス | 波面グリッドの光線をスネルの法則で屈折させ、面積比から集光強度を計算（エネルギー保存・タイル化）。分散で虹色の縁 |
| 水面（下から） | スネルの窓（臨界角 48.6°）、窓の外は全反射、フレネル、雲と太陽 |
| 色の見え方 | 眼の明順応（深さ・見上げ角）と部分的な色順応（von Kries） |
| ライト | 水中ライトは光路で減衰し、ビームが散乱して見える。赤い色が戻る |
| 生物 | 群泳（ボイド）、サンゴ上の群れ、ペア、隠れる・逃げる反応。尾びれの推進波を頂点シェーダで |
| 粒子 | マリンスノー、吐いた泡（ボイルの法則で上昇とともに膨張）、着底時の砂煙 |
| 物理 | BCD・ウェットスーツ・肺の体積がすべて水深で変わる浮力、二次抵抗、フィンのキック推力 |
| ダイコン | Bühlmann ZHL-16C（GF 40/85）による NDL・減圧、浮上速度、安全停止、残圧（SAC） |
| 音 | Web Audio で合成：レギュレーターの吸気、排気の泡、テッポウエビのパチパチ音、波音 |

## 操作

| | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / Shift で強くキック | 左側ドラッグ（スティック）/ ≫ |
| 視点 | マウス（クリックでロック） | 右側ドラッグ |
| 浮力（リアル） | E 給気・Q 排気、Space 深く吸う・C 吐き切る | ▲▼ で BCD 給排気 |
| 上下（イージー） | Space 浮上・C 潜行 | ▲▼ |
| ライト / 撮影 / 図鑑 | F / P / Tab | 💡 / 📷 / 📖 |

水面まで浮上するとダイブ終了。ダイブログ（潜水時間・最大水深・SAC・安全停止の有無・出会った生き物）が表示される。

## 開発

```bash
npm install
npm run dev       # 開発サーバ（スマホからは表示される LAN の URL へ）
npm run build     # dist/ に静的ファイルを出力
npm test          # 浮力・ガス消費・減圧モデルのテスト
npm run e2e       # Playwright でダイブ開始〜ログまでのスモークテスト（vite preview を起動しておく）
npm run shots -- http://localhost:4173/ tulamben high '[{"x":-24,"y":-10,"z":-94,"yaw":3.14,"pitch":-0.25}]'
```

`main` に push すると `.github/workflows/deploy.yml` が GitHub Pages に公開する（リポジトリ設定で Pages のソースを「GitHub Actions」にする）。

### 構成

```
src/
  main.js        ゲーム全体（ロード、ループ、UI）
  water.js       水の光学定数と、全マテリアルを水中ライティングにするシェーダパッチ
  post.js        水の媒質（吸収・散乱・光の筋・ライトのビーム）、ブルーム、トーンマップ
  caustics.js    物理ベースのコースティクス
  surface.js     水面（スネルの窓）
  terrain.js     海底地形・砂紋・岩
  reef.js / reefgeo.js  サンゴ・海綿・ウミウチワ・イソギンチャクの生成と配置
  wreck.js       USAT リバティ号
  fish.js        魚の形状・模様・群泳
  creatures.js   ウミガメ、マンタ
  particles.js   マリンスノー、泡、砂煙
  diver.js / deco.js   ダイバー物理と減圧計算
  audio.js       合成サウンド
  hud.js / input.js    ダイブコンピュータ表示と操作
```

### 画質

自動ではスマホ＝低、PC＝高。高はシャドウ・MSAA・光の筋 22 ステップ・密なサンゴ（約 400 万ポリゴン）、低は約 80 万ポリゴン。
