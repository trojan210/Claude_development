# レポート生成の指示文

ルールの正本は [`../project_knowledge/レポート作成ルール.md`](../project_knowledge/レポート作成ルール.md) にある。
**このファイルに本文を複製しない。** 複製すると必ず片方が古くなる。

## Claude Code で使うとき

> `project_knowledge/レポート作成ルール.md` を読み、そのルールに従って
> `reports/<年度学期>/<科目>_<課題名>/assignment.md` の設問に答えるレポートを
> 同ディレクトリの `draft.md` に書け。

## ホームのチャットで使うとき

プロジェクト機能を使う場合は `project_knowledge/README.md` の手順で設定する。
プロジェクトを使わない場合は、Notion の「設定 > 指示文」からコードブロックを貼る。
