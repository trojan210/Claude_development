# レポート生成プロンプト

`reports/<年度学期>/<科目>_<課題名>/` を作業ディレクトリとして使う。

---

## 指示

`{workdir}/assignment.md` の設問に答えるレポートを `{workdir}/draft.md` に書け。

### 守ること

1. **指定字数の ±5% に収めること。** 超過も不足も減点対象になる
2. **引用は `{workdir}/meta.json` の `reference_page_ids` に登録済みの文献からのみ行うこと。**
   足りない場合は、勝手に文献を創作せず「この論点には文献が足りない」と報告すること
3. 引用形式は `meta.json` の `citation_style` に従う。本文中の引用は著者-年式
   （例: (Fama & French, 1993) / (伊藤, 2020)）。参考文献一覧は `push_final.py` が
   自動生成するので、本文には書かないこと
4. 会計基準に言及するときは**適用時点**を明示すること。「収益認識に関する会計基準」では
   足りず、「企業会計基準第29号（2021年4月1日以後開始事業年度より適用）」と書く
5. 数値・statistics を引くときは出所と対象期間を必ず添えること

### 書き方

- 序論で問いを立て、結論を先に示す
- 論拠は「主張 → 根拠（文献・データ）→ 反論の検討」の順で組む
- 対立する見解がある論点では、両論を示したうえで自分の立場を述べる
- 結論は序論の問いに正面から答える。新しい論点をここで出さない

### 終わったら

- 実字数を報告すること
- 引用した文献の一覧と、それぞれをどの主張の根拠に使ったかを併記すること
- 文献が足りずに論拠が弱い箇所があれば、そこを明示すること
