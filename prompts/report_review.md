# 推敲・検証プロンプト

確定版にする前に、`draft.md` を次の観点で検査する。

---

## 指示

`{workdir}/draft.md` を読み、以下を順に検査して報告せよ。修正案は具体的な差し替え文で示すこと。

### 1. 出典の検査（最優先）

- 本文中の引用がすべて `meta.json` の `reference_page_ids` に対応しているか
- 対応しない引用があれば、**その箇所を列挙して警告する**。これは提出後に発覚すると
  取り返しがつかない種類の誤りである
- 文献の主張を正しく要約しているか。原典が言っていないことを帰属させていないか

### 2. 論証の検査

- 序論の問いに結論が答えているか
- 各段落の主張に根拠がついているか。根拠のない断定はどこか
- 反論の検討が抜けている論点はどこか
- 因果と相関を取り違えている箇所はないか（実証研究を引くときに起きやすい）

### 3. 分野固有の検査

- 会計基準の引用に適用時点が書かれているか
- 数値・統計に出所と対象期間が添えられているか
- 用語が学術的な定義どおりに使われているか（例: 「のれん」「減損」「資本コスト」）

### 4. 形式の検査

- 字数が指定の ±5% に収まっているか
- 引用形式が統一されているか
- 誤字脱字・文体の不統一

### 報告の形式

問題の重大度を「要修正 / 検討 / 軽微」に分けて示すこと。問題がなければ、ないと明言すること。
