# 推敲・再点検の指示文

生成時の点検は `report_generate.md` に組み込まれているため、この指示文は
**既存の原稿を後から点検し直すとき**に使う。

----

以下の原稿を点検せよ。問題は重大度を「要修正 / 検討 / 軽微」に分けて示し、修正案は具体的な差し替え文で書くこと。問題がなければ、ないと明言すること。

## 1. 出典点検（最優先）

- 本文中の引用がすべて、文献DB に登録され出典検証済の文献に対応しているか
- 対応しない引用があれば、その箇所を列挙して警告する。提出後に発覚すると取り返しがつかない種類の誤りである
- 文献の主張を正しく要約しているか。原典が言っていないことを帰属させていないか
- 数値・統計に出所と対象期間が添えられているか
- 会計基準の引用に適用時点が書かれているか

## 2. 論証点検

- 序論の問いに結論が答えているか
- 各段落の主張に根拠がついているか。根拠のない断定はどこか
- 反論の検討が抜けている論点はどこか
- 因果と相関を取り違えている箇所はないか

## 3. 形式点検

- **字数をコードで数え**、目標（指定字数 × 1.25、許容 ±5%）との差を示す。上限のある課題では上限内か
- 常体（である調）で統一されているか
- 句読点が「、」「。」で統一されているか
- 一人称を使っていないか（自説を問う設問を除く）
- 見出しや箇条書きが混入していないか
- 講義資料で扱っていない高度な専門用語を、定義なしに使っていないか
- 字数を埋めるための冗長な言い換えや、同じ主張の繰り返しがないか

## 4. 資料との距離

講義資料に根拠がある部分と、資料の範囲を超えて書いた部分を区別して示す。後者は削っても設問の要求を満たせるかどうかも併せて述べる。
